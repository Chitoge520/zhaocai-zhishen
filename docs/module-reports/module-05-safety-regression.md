# 模块五开发报告：安全边界、任务控制与回归验证

## 1. 模块目标

本模块面向比赛现场和真实上传场景，补齐系统在“不可信压缩包、长时间 OCR、网络大模型配置和多任务操作”下的边界控制。目标不是增加复杂功能，而是让系统在演示时可控、失败时可解释、输入异常时不会无限消耗资源。

## 2. 已完成内容

### 2.1 压缩包安全边界

修改 `src/zhaocai_zhishen/datasets/organize_internal_archives.py`：

- 单个压缩包成员最大解压大小：256 MB；
- 单个任务最大解压总大小：2 GB；
- 单个压缩包及嵌套压缩包累计文件数量：5,000 个；
- 嵌套压缩包最大递归深度：2 层；
- 解压前先检查 `ZipInfo.file_size`，超限时不会进入文件写入和 OCR；
- 保留原有文件名清理和输出目录隔离逻辑。

这组限制同时覆盖普通文件和嵌套压缩包，避免仅限制外层 ZIP 而被内部 ZIP 绕过。

### 2.2 文件分类增强

增加通用附件上下文恢复：

- 当一个项目压缩包已经出现明确的投标文件时，`附件1.pdf`、`报价函.docx`、`资格证明.pdf` 等通用文件名可以在投标上下文中提升为投标文件；
- 如果通用附件位于招标、评标或参考材料目录，则保持原分类，避免把招标附件误纳入投标样本；
- 通用附件不强行猜测投标人名称，避免把“附件1”错误作为公司名。

系统仍然把无法确定的文件保留在清单中，便于人工检查，不静默删除文件。

### 2.3 新项目任务控制

修改 `src/zhaocai_zhishen/job_manager.py` 和 `server.py`：

- 同时处于排队或运行状态的任务最多 4 个；
- GPU OCR 继续使用单一锁，避免同一张 GPU 被多个 OCR 进程同时抢占；
- 单个后台任务最长运行 2 小时，阶段切换时检查超时；
- 新增取消接口：

```text
POST /api/projects/jobs/{job_id}/cancel
```

- 前端任务列表对排队/运行任务显示“取消”按钮；
- 取消请求会在当前阶段结束后被识别，任务状态变为 `cancelled`；
- 失败任务仍保留 `error.log` 和阶段状态，便于现场排查。

### 2.4 大模型地址白名单

修改 `src/zhaocai_zhishen/llm_analysis.py` 和 `server.py`：

- 默认只允许 `https://api.deepseek.com`；
- `DEEPSEEK_ALLOWED_HOSTS` 可以在启动前配置受信任域名白名单；
- 默认拒绝明文 HTTP、本机地址、IP 地址和未列入白名单的域名；
- 仅在显式设置 `BID_AUDIT_ALLOW_LOCAL_LLM_HTTP=1` 且把本机域名加入白名单时，允许本地 HTTP 调试；
- 拒绝带账号、密码、查询参数或片段的 API 地址，减少地址解析和密钥外发风险。

API 密钥仍只存在当前服务进程环境变量中，不写入代码、报告或任务文件。

### 2.5 配置目录统一

修改 `src/zhaocai_zhishen/config.py`：

- 未设置 `BID_AUDIT_DATA_DIR` 时统一使用项目根目录下的 `data`；
- 设置环境变量时仍支持将历史数据放到外部目录；
- 消除了原先通过父目录名称猜测数据目录的隐式行为，减少服务和 CLI 读取不同数据位置的风险。

## 3. 测试与验证

当前测试结果：

```text
该模块完成时 29 项 unittest 全部通过；M0 总体验收以当前 46 项测试为准
src 全量 compileall 通过
```

新增安全边界测试：

- 超大压缩包成员在解压前被拒绝；
- 不可信 DeepSeek 域名和明文 HTTP 被拒绝；
- 本机 HTTP 只有显式配置后才允许；
- 通用附件只有处于投标上下文时才会升级分类。

## 4. 现场可见效果

评委上传一个正常 ZIP 时，系统会显示任务阶段和进度；上传超限或没有投标文件的 ZIP 时，会在整理阶段给出失败原因；任务过长时不会无限占用后台；大模型配置页面不会接受任意外部地址；任务列表可以取消不需要继续处理的项目。

## 5. 尚未覆盖的边界

- Python 线程无法强制中断已经卡住的第三方 OCR 调用，当前超时检查会在阶段边界生效；
- Windows 现场如果没有 LibreOffice，DOCX 仍只能做结构验证，无法做页面级渲染；
- 当前没有持久化人工复核结果，也没有把复核结果加入训练反馈闭环；
- 文件角色识别仍是规则和上下文启发式，不应在报告中声称达到百分之百准确。
