# 模块六：重复片段证据增强

## 1. 模块目标

在现有的文本相似度、电话、邮箱、统一社会信用代码、联系人和地址特征之外，增加可回放的“成段重复文本”证据。

本模块不把重复片段直接等同于串标、围标或违规行为。投标文件可能依法复用合同条款、技术规范和招标文件模板，因此重复片段只作为已有异常线索的佐证，不单独触发异常线索。

## 2. 实现内容

### 2.1 重复片段提取

- 对每份文档生成 48 字符、步长 16 的归一化文本窗口；
- 排除字符种类过少或明显 OCR 噪声窗口；
- 每份文档只保留窗口首次出现位置，便于后续定位；
- 使用跨文档频次排除至少 3 份文件共同出现的公共模板片段；
- 过滤与公共模板存在较长重叠的边界窗口，降低模板和自定义内容拼接造成的误报。

### 2.2 异常分析接入

`pairwise_similarity.csv` 新增字段：

- `repeated_segment_count`：两份文件的重复片段数量；
- `repeated_segment_chars`：去重后重复片段覆盖字符数；
- `repeated_segments`：可回放的重复片段样本。

`anomaly_results.csv` 同步保存上述字段，并将重复片段加入证据摘要和双方证据页定位。

触发规则保持保守：只有共享实体、实体交叉佐证或高文本相似度已经满足原有线索条件时，重复片段才会以最多 4 分的幅度增强线索分数。

### 2.3 无监督模型接入

冻结模型新增两个无监督排序特征：

- `repeated_segment_count`；
- `repeated_segment_chars_k`，即重复字符数除以 1000 后的缩放值。

模型仍使用稳健统计和项目级交叉验证，不需要人工标签，不输出违法概率。旧的 CSV 如果没有新增字段，会按 0 读取，保证历史产物兼容。

### 2.4 前端和报告展示

- 项目总览增加“重复片段证据”统计；
- 历史数据集增加“模板片段排除”统计；
- 异常线索详情展示重复片段数量和字符覆盖量；
- HTML 和 DOCX 报告增加重复证据和公共模板排除统计；
- 证据页仍然回到原始文档页码，不展示无法定位的模型推断。

## 5. 比赛展示价值

评委在异常线索详情中可以看到：

1. 哪两个投标人被比较；
2. 文本相似度和异常分数；
3. 共同电话、地址等结构化实体；
4. 两份文件中连续重复的文本片段；
5. 双方对应的原始页码。

展示重点应表述为“多层证据融合后形成可追溯待复核线索”，而不是“模型凭重复文字认定串标”。
