# 模块八开发报告：关系图谱可读性重构

## 1. 模块目标

解决原关系图谱中节点标签相互遮挡、不同类型的连线混在一起、固定画布空间不足以及证据列表不易扫描的问题。

本模块只优化关系展示和证据定位，不改变无监督模型分数，也不把图谱关系直接解释为串标、围标或违法违规结论。

## 2. 原有问题

- 节点名称直接绘制在圆点内部，长公司名称会覆盖节点和连线；
- 项目、投标人、文件、电话、地址和相似关系全部同时出现，视觉噪声较大；
- 画布固定为 760×390，节点数量增加后容易拥挤；
- 线条只有颜色和粗细差异，缺少明确的关系类型筛选；
- 右侧证据列表使用普通报告段落，无法快速区分共享实体和文本相似线索。

## 3. 实现内容

文件：`src/zhaocai_zhishen/static/index.html`

### 3.1 分层布局

图谱改为左右分层布局：

- 左侧：投标人节点；
- 右侧：共享电话、邮箱、地址、联系人等实体节点；
- 投标人之间的文本相似关系通过左侧弧线单独显示；
- 节点文字移出圆点，使用独立文本区域展示，并保留完整名称 `title` 提示。

### 3.2 关系筛选

新增两个控制：

- `核心线索（默认）`：先锁定达到模型阈值的文本相似关系，再只展开与这些重点投标人相连的共享实体；如果项目没有高分相似关系，则退化为展示共享实体最多的少量投标人；
- `全部关联`、`文本相似`、`共享实体`：用于切换检查范围；
- `只显示有证据的关系`：默认开启，过滤没有证据入口的普通边。

原始图谱中的“项目参与”和“提交文件”边不再默认挤入审计关系网络，避免把导航关系误认为风险关系；文件信息仍保留在证据回放和报告中。

### 3.3 自适应空间和清晰连线

- 画布高度根据投标人和实体数量动态计算；
- 使用虚线分隔投标人区和实体区；
- 高于异常阈值的文本相似关系使用红色粗线；
- 普通相似关系使用灰色弱线；
- 共享实体关系使用绿色曲线；
- 文本相似线旁显示相似度对应的异常分数；
- 页面右侧将共享实体按实体归并，避免同一个实体重复出现多张无意义卡片。

### 3.4 移动端适配

在较窄窗口下，图谱和证据列表自动改为上下布局，画布保持横向滚动，不压缩节点文字到不可读的程度。

## 5. 使用说明

进入“关系图谱”后：

1. 先选择项目；
2. 默认查看“重点关联”；
3. 如果需要检查所有文本相似关系，切换到“文本相似”；
4. 如果需要检查企业实体交集，切换到“共享实体”；
5. 右侧卡片中的线索 ID、分数和证据摘要用于进入原始文件和页码复核。

## 6. 边界说明

图谱的作用是缩短从“异常分数”到“原文证据”的路径。共享实体、文本相似或图上的连接关系都需要结合报价结构、文件元数据、项目背景和人工复核，不能单独作为串标、围标或违规结论。
