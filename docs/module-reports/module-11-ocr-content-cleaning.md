# 模块 11：OCR 有效内容清洗

## 1. 问题

原始 OCR 文本中存在页眉页脚重复、同页双栏重复识别、表格标题重复和整页重复扫描等噪声。直接将这些文本用于 TF-IDF 和重复片段分析，会放大模板相似度，增加无效证据。

## 2. 处理原则

- 文档级分析文本使用清洗后的有效内容；
- `pages.jsonl` 的 `text` 字段保留原始 OCR 文本，用于证据回放；
- 页面同时写入 `cleaned_text`，便于检查清洗结果；
- 只删除高频页眉页脚、同页重复行和重复整页，不删除原始证据；
- 清洗发生在 OCR 之后、实体抽取和相似度分析之前。

## 3. 当前结果

对现有 63 份文档执行清洗：

```text
分析文本字符数：7,450,481

冗余减少比例：5.37%
```


当前唯一线索仍然是同一项目内两份不同投标文件之间的关系。清洗后异常分数为 77.89，主要证据包括共同电话、共同邮箱、共同地址和非公共重复片段。该结果仍然只是待复核线索，不是违规结论。

## 5. 运行方式

以后执行 `prepare` 时会自动使用 `ocr-cleanup/v1` 清洗规则，缓存版本已升级为 `v4`，不会继续复用旧的未清洗缓存。

```powershell
.\run.ps1 prepare --ocr auto --ocr-engine paddle-gpu --force
.\run.ps1 analyze
```

清洗规则代码位于 `src/zhaocai_zhishen/document_pipeline.py`，对应回归测试位于 `tests/test_document_pipeline.py`。
