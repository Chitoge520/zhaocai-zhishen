# 模块 12：大模型辅助 OCR 校正

## 1. 目标

规则清洗可以删除重复内容，但不能可靠修正 OCR 将“邮箱、网址、投标文件、地址、金额”等字段识别错的问题。本模块使用已配置的大模型对少量疑似错误页面进行辅助校正。

## 2. 安全边界

- 默认只选择疑似错误页面，不发送完整项目或完整文档；
- 电话、邮箱、统一社会信用代码和证件号先替换成稳定占位符；
- 大模型必须原样保留占位符，否则结果被本地拒绝；
- 只允许引用输入页面，不允许大模型新增事实；
- 原始 OCR 存在 `pages.jsonl` 的 `text` 字段，不会被覆盖；
- 校正结果先写入独立的 `ocr_llm_result.json`，不自动替换生产分析文本。

## 3. 当前流程

```text
OCR 原文
  -> 规则去重
  -> 识别疑似 OCR 错误页面
  -> 脱敏后发送大模型
  -> 校验页码、文档 ID、占位符和长度
  -> 保存旁路校正结果
  -> 人工或规则确认后再应用
```

## 4. 运行命令

```powershell
.\run.ps1 enhance-ocr --input data/processed --output data/ocr_llm
```

大模型未启用或没有密钥时，命令会安全跳过，不影响本地 OCR、异常分析和模型推理。

## 5. 适合校正的内容

- OCR 错别字和中英文混排错误；
- 电话、邮箱、网址等字段的标签识别；
- 页内断行和简单表格顺序；
- 项目名称、招标编号、投标人名称等结构化字段。

## 6. 不交给大模型决定的内容

- 是否串标、围标或违法；
- 是否将某个共同地址认定为风险；
- 报价是否构成异常；
- 是否删除原始页面证据。

本模块测试覆盖脱敏、占位符恢复、未知页面拒绝等路径。当前全项目测试共 46 项，全部通过。
